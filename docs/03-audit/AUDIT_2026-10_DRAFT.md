## B. .vbook format

A `.vbook` is a zip of JSON files. On disk (per code) it is a directory: `manifest.json`, `book.json`, optional `bible.json`/`characters.json`/`locations.json`/`voices.json`/`behavior.json`, and `chapters/ch-*.json` (schema description at `packages/animastor-vbook-runtime/schemas/vbook-bundle-3.1.schema.json:5`). `MiM.vbook` (backend root; md5 `91e8983b…`; last committed `ac3e3d5` 2026-07-28) unzips to **9 files**: `manifest.json, book.json, bible.json, characters.json, locations.json, voices.json, chapters/ch-{2a7fee78,319c798a,ce87fec4}.json` — **no `source.txt` and no `mentions.json`** in this sample.
